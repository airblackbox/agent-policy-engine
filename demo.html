Risk-Tiered Autonomy
Different actions get different levels of oversight

Tier 1 — Low Risk

  • ✓ Read-only operations
  • ✓ Internal tool calls
  • ✓ Data lookups
  • ✓ Summarization tasks

→ Auto-approved

Tier 2 — Medium Risk

  • ⚠ External API calls
  • ⚠ File modifications
  • ⚠ Data exports
  • ⚠ Multi-step workflows

→ Logged + rate-limited

Tier 3 — High Risk

  • ✗ Financial transactions
  • ✗ PII access / sharing
  • ✗ Privilege escalation
  • ✗ External comms

→ Human approval required

policies:

SDK integration (Python)
from air_blackbox import PolicyEngine

engine = PolicyEngine("http://policy-engine:9090")

# Before every agent action:
decision = engine.evaluate(
    agent="research-bot-v2",
    action="tool.search",
    context={"query": "competitor pricing"}
)

if decision.allowed:
    result = execute_tool(action)
else:
    log.warning(f"Blocked: {decision.reason}")
