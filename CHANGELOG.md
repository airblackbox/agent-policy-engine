# Changelog

All notable changes to **Agent Policy Engine** will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-02-22

- Initial release of the Policy Engine
- Real-time policy evaluation for LLM requests
- Rate limiting, budget caps, and tool restriction rules
- Kill switch for runaway agent detection
- Content matching and risk tier classification
- CORS support for browser-based dashboard access
- Dockerfile for container deployment
